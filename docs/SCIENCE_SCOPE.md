# Scientific Scope and Limitations

## What V1 can legitimately say

V1 can say:

- a catalogue equilibrium temperature lies in a project-defined cool/moderate/hot bin;
- a catalogue radius lies in a project-defined small/intermediate/giant bin;
- a combination of those broad properties is compatible with a broad environmental profile;
- more evidence is required to determine atmospheric molecules.

## What V1 must NOT say

V1 must not say:

- a molecule definitely exists because a planet has a particular temperature;
- a planet is habitable from equilibrium temperature alone;
- the local snapshot is real-time data;
- the project simulates a complete astrochemical reaction network;
- NASA has validated the project's custom rules.

## NASA snapshot provenance

The local CSV contains selected values transcribed from official NASA Exoplanet Archive overview pages for:

- TRAPPIST-1 g
- Kepler-22 b
- HD 209458 b

The archive displays multiple literature solutions for many parameters. V1 records representative values only for a reproducible classroom demonstration.

For a future research version, the project should retrieve a formally defined table/query and preserve parameter references/uncertainties systematically.
